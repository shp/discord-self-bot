# Discord Self Bot

## setup
> git clone https://github.com/shp/discord-self-bot
> cd discord-self-bot  
> npm i  
> npm run build

## run
> npm start

## config.json

```json
{
  "CLIENT_TOKEN": "string",
  "PREFIX": "!",
  "ADDRESSES": {
    "BTC": "string",
    "ETH": "string",
    "LTC": "string",
    "SOL": "string",
  }
}
```

## info
- using this can get you banned
- other people can run the commands by default by pinging you with it or dming you it
- there is a help command to view the commands
